PIRLOFIG PERSONAL WEBSITE

Struktur:
pirlofig/
├── index.html
├── css/
│   └── main.css
├── js/
│   └── main.js
└── assets/
    └── images/

CARA MENJALANKAN:
1. Pastikan index.html, folder css dan js berada dalam folder yang sama.
2. Buka index.html menggunakan Chrome/Edge.
3. Untuk mengubah tampilan, edit css/main.css.
4. Untuk mengubah interaksi/menu/animasi, edit js/main.js.
5. Tambahkan foto pribadi ke assets/images/ lalu ubah bagian avatar di index.html jika ingin memakai foto.

CATATAN:
- Email, Instagram, GitHub, dan data pribadi di index.html masih placeholder.
- Website tidak membutuhkan internet untuk CSS/JavaScript karena semuanya lokal.
